- Un soporte de trazabilidad total

3. TECNOLOGÍA UTILIZADA
============================================================

Frontend:
- FlutterFlow
- App nativa (mobile-first)

Backend:
- Supabase
- Base de datos relacional
- Storage para firmas, remitos e imágenes

Motivo de elección:
- Rapidez de iteración
- Control total del modelo de datos
- Validación temprana con operación real

============================================================
4. PRINCIPIOS DE DISEÑO
============================================================

- La operación manda sobre la administración
- Primero sucede el evento, luego se registra
- Nada se estima: todo se mide o se confirma
- Todo es editable hasta el cierre
- El cierre genera documentos definitivos
- Recolección y Distribución son procesos distintos

============================================================
5. ENTIDADES PRINCIPALES
============================================================

Usuario:
- Roles reales: Chofer, Compras, Depósito, Administración

Vehículo:
- Camión físico con capacidades definidas

Viaje:
- Unidad logística madre
- Relaciona vehículo + chofer + fechas

Parada:
- Evento operativo dentro de un viaje
- Tipo: Recolección o Distribución
- Ubicación, cliente y fecha real

Ítem de Parada:
- Producto involucrado
- Cantidad planificada

============================================================
6. PROCESO DE RECOLECCIÓN
============================================================

Definición:
La Recolección es el ingreso de mercadería al sistema.

Características:
- Se reciben tambores físicos
- El peso total es desconocido hasta pesaje
- El pesaje es obligatorio

Flujo:
Viaje → Parada (Recolección) → Ítems → Pesajes → Totales → Remito

============================================================
7. PROCESO DE PESAJE
============================================================

El Pesaje es la unidad mínima e irreductible del sistema.

Cada pesaje representa un tambor e incluye:
- Código SENASA (11 dígitos)
- Peso bruto
- Tara
- Peso neto automático
- Consecutivo humano

Durante la carga:
- Se pueden agregar múltiples pesajes
- Se permite editar y eliminar
- Se visualizan totales en tiempo real

Cierre del pesaje:
- Se consolidan totales
- Se bloquea la edición
- Se genera Remito

============================================================
8. PROCESO DE DISTRIBUCIÓN
============================================================

Definición:
La Distribución es el egreso de mercadería ya existente.

Características:
- NO hay pesaje
- Los kilos ya están definidos
- Se controla producto y cantidad entregada

Flujo:
Viaje → Parada (Distribución) → Ítems → Entrega → Remito

No permitido:
- Re-pesaje
- Alteración de kg netos

============================================================
9. REMITO (DOCUMENTO DE CIERRE)
============================================================

El Remito es el documento final e inmodificable.

Recolección:
- Apicultor
- Localidad
- Fecha
- Productos
- Cantidad de tambores
- Totales Bruto/Tara/Neto
- Chofer y vehículo
- Firma

Distribución:
- Cliente receptor
- Localidad
- Fecha
- Productos
- Cantidad entregada
- Kg netos definidos
- Chofer y vehículo
- Firma

============================================================
10. MOVIMIENTOS DE STOCK
============================================================

Los movimientos son consecuencia automática:
- Recolección → ingreso
- Distribución → egreso

No son pantallas de trabajo.
Sirven para reportes y control.

============================================================
11. TRAZABILIDAD TOTAL
============================================================

El sistema permite reconstruir:

Tambor → SENASA → Pesaje → Ítem → Parada → Viaje → Vehículo → Chofer → Remito

```dart
import 'package:flutter/foundation.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

class VijesService extends ChangeNotifier {
  List<Map<String, dynamic>> _viajes = [];
  bool _loading = false;
  String? _error;

  // Getters
  List<Map<String, dynamic>> get viajes => _viajes;
  bool get loading => _loading;
  String? get error => _error;

  // Constructor - puede recibir dependencies inyectadas
  VijesService({SupabaseClient? client}) {
    _client = client ?? Supabase.instance.client;
  }

  late final SupabaseClient _client;

  // Método público (testeable)
  Future<void> cargarViajes() async {
    try {
      _loading = true;
      _error = null;
      notifyListeners();

      final data = await _client
          .from('viajes')
          .select()
          .order('fecha', ascending: false);

      _viajes = List<Map<String, dynamic>>.from(data ?? []);
    } catch (e) {
      _error = 'Error al cargar viajes: $e';
      _viajes = [];
    } finally {
      _loading = false;
      notifyListeners();
    }
  }

  Future<void> crearViaje(Map<String, dynamic> data) async {
    try {
      await _client.from('viajes').insert(data);
      await cargarViajes(); // Recargar
    } catch (e) {
      _error = 'Error: $e';
      notifyListeners();
      rethrow;
    }
  }

  Future<void> actualizarViaje(int id, Map<String, dynamic> data) async {
    try {
      await _client.from('viajes').update(data).eq('id', id);
      await cargarViajes();
    } catch (e) {
      _error = 'Error: $e';
      notifyListeners();
      rethrow;
    }
  }

  void limpiar() {
    _viajes = [];
    _error = null;
    notifyListeners();
  }
}
```

```dart
// lib/backend/services/viajes_service.dart
class VijesService extends ChangeNotifier {
  static const int PAGE_SIZE = 20;
  int _currentPage = 0;
  bool _hasMore = true;

  Future<void> cargarMasPaginas() async {
    if (!_hasMore) return;

    final offset = _currentPage * PAGE_SIZE;
    
    final data = await Supabase.instance.client
        .from('viajes')
        .select()
        .order('fecha', ascending: false)
        .range(offset, offset + PAGE_SIZE - 1);  // ✅ Paginación

    if ((data as List).length < PAGE_SIZE) {
      _hasMore = false;
    }

    _viajes.addAll(data);
    _currentPage++;
    notifyListeners();
  }
}
```

```dart
class ParadaProvider extends ChangeNotifier {
  late final Parada _parada;
  late final _CachedCalculations _cache;

  ParadaProvider(this._parada) {
    _cache = _CachedCalculations(_parada);
  }

  double get pesoTotal => _cache.pesoTotal;
  double get taraTotal => _cache.taraTotal;

  void actualizarItem(ItemParada item) {
    _parada.actualizarItem(item);
    _cache.invalidate();  // ✅ Invalidar caché
    notifyListeners();
  }
}

class _CachedCalculations {
  final Parada parada;
  double? _pesoCache;
  double? _taraCache;

  _CachedCalculations(this.parada);

  double get pesoTotal => _pesoCache ??= _calcular();
  double get taraTotal => _taraCache ??= _calcularTara();

  void invalidate() {
    _pesoCache = null;
    _taraCache = null;
  }
}
```

```dart
import 'package:flutter/foundation.dart';
import 'package:supabase_flutter/supabase_flutter.dart';
import 'package:flutter_secure_storage/flutter_secure_storage.dart';

class AuthService extends ChangeNotifier {
  late final SupabaseClient _client;
  late final FlutterSecureStorage _storage;
  
  User? _currentUser;
  String? _error;

  // Getters
  User? get currentUser => _currentUser;
  String? get error => _error;
  bool get isLoggedIn => _currentUser != null;

  AuthService({
    SupabaseClient? client,
    FlutterSecureStorage? storage,
  }) {
    _client = client ?? Supabase.instance.client;
    _storage = storage ?? const FlutterSecureStorage();
  }

  Future<bool> login(String email, String password) async {
    try {
      _error = null;
      notifyListeners();

      final response = await _client.auth.signInWithPassword(
        email: email,
        password: password,
      );

      if (response.user != null) {
        _currentUser = response.user;
        
        // Guardar token securo
        await _storage.write(
          key: 'auth_token',
          value: response.session?.accessToken,
        );

        notifyListeners();
        return true;
      }
    } catch (e) {
      _error = 'Login failed: $e';
      notifyListeners();
      return false;
    }

    return false;
  }

  Future<void> logout() async {
    try {
      await _client.auth.signOut();
      _currentUser = null;
      await _storage.delete(key: 'auth_token');
      notifyListeners();
    } catch (e) {
      _error = 'Logout failed: $e';
      notifyListeners();
    }
  }

  Future<bool> restoreSession() async {
    try {
      final token = await _storage.read(key: 'auth_token');
      if (token != null) {
        _currentUser = _client.auth.currentUser;
        notifyListeners();
        return _currentUser != null;
      }
    } catch (e) {
      _error = 'Restore session failed: $e';
    }
    return false;
  }
}
```
